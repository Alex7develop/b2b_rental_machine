# Реализованные цели Яндекс.Метрики

## 📊 Общие цели (главные для маркетинга)

### 1. ✅ Успешная отправка любой формы

- **Цель**: `form_success_any`
- **Когда срабатывает**: При успешной отправке любой формы на сайте ИЛИ при переходе на страницу благодарности
- **Покрытие**:
  - ContactForm (главная форма)
  - HowItWorksForm (форма дегустации)
  - Modal (модальная форма подбора кофемашины)
  - Страница благодарности `/thanks`

### 2. ✅ Открытие любой формы

- **Цель**: `modal_open`
- **Когда срабатывает**: При клике на любую кнопку, открывающую форму или модальное окно
- **Покрытие**:
  - Кнопка "Оставить заявку" в хедере (десктоп)
  - Кнопка "Оставить заявку" в мобильном меню
  - Кнопка "Оставить заявку" в Hero секции
  - Кнопка "Попробуйте бесплатно" в AboutUs
  - Кнопка "Записаться на дегустацию" в AboutUs
  - Кнопки "Записаться" в карточках кофемашин
  - Кнопка "Записаться на дегустацию" в WhyUs
  - Кнопка в аккордеоне WhyUs
  - Иконка "Подобрать кофемашину" в Hero

### 3. ✅ Клик по номеру телефона

- **Цель**: `phone_click`
- **Когда срабатывает**: При клике на любой телефонный номер
- **Покрытие**:
  - Телефон в Hero секции
  - Телефон в ContactForm
  - Телефон в HowItWorksForm
  - Иконки телефонов в контактных блоках

### 4. ✅ Клик по email + копирование

- **Цель**: `email_choice` (клик), `email_copy` (копирование), `email_select` (выделение), `email_context_menu` (правая кнопка)
- **Когда срабатывает**:
  - При клике на email адрес
  - При нажатии Ctrl+C на сфокусированном email
  - При выделении email
  - При правой кнопке мыши на email
- **Покрытие**:
  - Email в Hero секции
  - Email в ContactForm
  - Иконки email в контактных блоках

### 5. ✅ Клик по переходу в WhatsApp

- **Цель**: `whatsapp_click`
- **Когда срабатывает**: При клике на кнопку WhatsApp
- **Покрытие**:
  - Иконка WhatsApp в контактных блоках ContactForm

## 📋 Техническая реализация

### Файлы с кодом целей:

- `public/yandex-goals.js` - Основной файл с обработчиками
- `src/pages/ThanksPage.tsx` - Цель при переходе на страницу благодарности
- `src/components/Hero/Hero.tsx` - Обработчики для Hero секции
- `src/components/ContactForm/ContactForm.tsx` - Обработчики для ContactForm

### Глобальные функции:

- `window.sendFormSuccessGoal(formType)` - Отправка цели при успешной отправке формы
- `window.sendThanksPageGoal()` - Отправка цели при переходе на страницу благодарности

### Особенности реализации:

1. **Двойные цели**: Каждая форма отправляет как специфичную цель, так и общую `form_success_any`
2. **Копирование email**: Поддержка Ctrl+C, правой кнопки мыши и выделения
3. **Фокусируемые элементы**: Email элементы имеют `tabIndex={0}` для работы с клавиатурой
4. **Fallback для копирования**: Поддержка старых браузеров через `document.execCommand`
